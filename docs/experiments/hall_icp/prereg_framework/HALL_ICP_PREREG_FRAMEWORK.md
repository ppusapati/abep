Outcomes: `hall_c1_reference`, `hall_icp_neutralizer`, `NO_VIABLE_CASE`. Statuses: `OPEN`, `NOT_EVALUATED`.

OPEN is a status, not an outcome; if evidence cannot decide, report unresolved and identify the next discriminating test (row 38)

NET_BENEFIT = hard gates first, then a Pareto report of dXe, dP_bus, dmass, T/P_bus, restart and life burden relative to C1; no weighted scalar and no single-scalar selection unless preregistered at LOCK-1 (row 37)

- **PASS_GATES(X)**: configuration X meets every hard gate (DQ-HI-SUST, DQ-HI-ECAP, DQ-HI-VCPL, DQ-HI-TABS, DQ-HI-PBUS, DQ-HI-PALLOC, DQ-HI-STAB, DQ-HI-SAFE, DQ-HI-IGN) at every required-envelope condition, each classification RESOLVED (DQ-HI-PALLOC applies to hall_icp_neutralizer only)
- **FAILS_GATES(X)**: at least one hard gate of X is RESOLVED as failed at a required condition
- **PARETO_REPORT**: for configurations passing the gates, each Pareto quantity with its interval relative to C1; relation classes NO_WORSE_ON_ALL(ICP) / NO_WORSE_ON_ALL(C1) / TRADE_OFF / UNRESOLVED are descriptive, never a ranking

|---|---|---|---|
| hall_icp_neutralizer | PASS_GATES(hall_icp_neutralizer) | PARETO_REPORT (mandatory) relative to hall_c1_reference | the downstream ICP neutralizer met every hard gate in this campaign; C1 remains the reference / fallback until the ICP also demonstrates restart and life (A9 control_fallback); not a flight baseline, not a selection |
| hall_c1_reference | FAILS_GATES(hall_icp_neutralizer) AND PASS_GATES(hall_c1_reference) | the failing ICP gates and their limits | the conventional C1 reference stays the reference / fallback; the ICP failure mode is reported |
| NO_VIABLE_CASE | FAILS_GATES(hall_icp_neutralizer) AND FAILS_GATES(hall_c1_reference) | failing gates per configuration | no configuration met the full-system gates; no case is forced to pass |

if any classification needed by the rules is UNRESOLVED, SUSTAINMENT_MIXED, NOT_SCOREABLE_FACILITY, NOT_TESTED or missing, the decision status is OPEN (never NO_VIABLE_CASE by default) and the next discriminating test is named (row 38)

the framework never declares a winner and never ranks configurations; outcomes are pre-registered classifications handed to the owner
