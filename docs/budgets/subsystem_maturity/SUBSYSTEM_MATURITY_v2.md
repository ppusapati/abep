### Scheduler rule (PROPOSED)

- **status**: PROPOSED rule for the owner (A7 names the four states and the one-blocker rule; the derivation below is this lane's)
- **precedence**: VERIFIED > RUNNING > BLOCKED > READY; the first condition that holds sets the state
- **VERIFIED**: every governing document of the row's interface cell is owner-frozen (interface_status FROZEN) AND every S1a / S1 readiness condition the row references is SATISFIED in the committed readiness status files AND the row references at least one such condition
- **RUNNING**: the row's single blocking item is worked by a REGISTERED H2 follow-on: the lane id is present in docs/orchestration/lane_registry_v1.json follow_ons (read, never pinned) and its registered scope (workflow script prompt, quoted verbatim and checked at build time) produces the missing input of that item
- **BLOCKED**: a single named blocking item exists and no registered lane works it (an owner decision, an H-1 / C-1 measurement (A7 wave H4, PLANNED_NOT_REGISTERED), a procurement action (wave H3, PLANNED_NOT_REGISTERED) or an item outside every registered scope)
- **READY**: no open blocking item
- **owner_decision_items**: a blocking item whose resolved state OR requires text (derived from its defining files: MCQ items via the hardware_requirements_v1 requirements that trace to them; BOM items via cbe.requires; JSON paths via their 'from' / 'now' / 'requires' strings) names an owner decision ('owner decision' / OPEN_OWNER_DECISION) is never RUNNING: no lane can take an owner decision; enforced at build time
- **non_lane_inputs**: likewise never RUNNING when that text requires a MEASURED hardware quantity (wave H4) or an ADMITTED Hall closure (credible set EMPTY): no registered H2 design lane produces either; enforced at build time
- **partial_scope**: RUNNING needs registered scopes that produce EVERY missing input the blocking item names; when registered lanes cover only part of it (checked against the item's own 'requires' text), they are listed under partial_scope and the row stays BLOCKED
- **one_blocker_rule**: every row carries exactly ONE blocking evidence/interface item (typed id resolved against its defining file); A7: every BLOCKED row points to exactly one item
- **lanes_that_mature_but_do_not_work_the_blocker**: an H2 lane that matures other aspects of a row is listed under h2_lanes but does not change the execution state
- **live_execution_state_of_lanes**: not read: the trigger ledgers are mutable and time-varying; RUNNING means 'assigned by registration and scope', not 'an agent is executing now'
