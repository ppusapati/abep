**What it is.** The common feed state delivered to the ionization/discharge block (valve outlet, ICD IF-A5; Xe port IF-X2) per altitude and atmosphere level, plus the orbit-averaged free-stream state that feeds the chain (ICD IF-A0), with producer, evidence class and uncertainty per value.

**What it is not.** Not a design, not a Hall prediction, not an architecture ranking, not a model change: no module is modified or wired, no frozen dataset is rebuilt, and no value depends on a Hall transport closure, an ensemble member or a P5 calibration-nuisance variable.

## 1. Chain and boundary

```
ambient -IF-A0-> intake -> filter -> compressor -> atmospheric gas chamber -> valve -IF-A5-+
                                                                                          +-> ionization/discharge
                                        Xe chamber (tank) -> Xe valve --------------IF-X2-+    (pre-ionizer: RF / ECR / none)
```

The feed state is defined at IF-A5 / IF-X2, upstream of any pre-ionizer, so the three architectures are compared at the same record. Chain mirrored (read, not imported or modified): abep_sim/archengine.py:gas_path_state -> abep_sim/system.py:evaluate (gaspath_physics=True): atmosphere -> intake.collection (TPMC) -> intake.compress (passive plenum) -> compressor.DragCompressor.size_for/run -> reservoir.Reservoir + size_orifice_for_pressure -> Reservoir.steady_state (mdot_anode, p_total_Pa, T_K, composition_anode_mass).
