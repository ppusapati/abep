## 2. Line topology and interface planes

```
compressor (C1) -N0/IF-A3-> [V0 isolation valve] -> N1 plenum -IF-A4-> V1 metering valve -N2/IF-A5-> T1 Xe tee
   (Xe anode line from Xe metering joins at T1) -> I1 gas isolator -> IP-UP -> [PIM-0 | PIM-RF | PIM-ECR] -> IP-DN
   -> H-1 stub -> D1 anode manifold ring (N_f feed points) -> D2 distributor -> HALL_INLET_Z0 -> channel
ground (H-1 test article): FS-C MFCs + bottles + mixing point + isolator + manifold gauge replace N0..T1
```
