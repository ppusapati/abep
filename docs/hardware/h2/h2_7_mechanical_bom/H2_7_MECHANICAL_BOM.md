## Margin policy (reused from mass_bom_v1)

MEV definition: MEV = sum_dry CBE x (1 + MGA) + system margin + propellant; system margin = fraction x nominal dry mass (nominal dry = sum_dry CBE x (1 + MGA)); propellant carries no MGA and no system margin (ESA R-M1-3). Standard: ESA SRE-PA & D-TEC staff, 'Margin philosophy for science assessment studies', SRE-PA/2011.097/, Issue 1, Revision 3, 15/06/2012 (technical note, marked 'ESA UNCLASSIFIED - For Official Use', publicly posted on sci.esa.int). Values used here: dry-equipment MGA 0.2 (ECSS D, PROPOSED), propellant MGA 0, system margin 0.2 (alternative 0.1), harness 0.05 of the nominal dry mass, Xe residual 0.02.

## Diagnostics

The mass model includes only the flight telemetry subset:

- TM-01 discharge voltage and current → R12 (inside PPU)
- TM-02 magnet coil current(s) (none if permanent magnets) → R12 (inside PPU)
- TM-03 cathode keeper and heater voltage / current → R12 (inside PPU)
- TM-04 Xe tank pressure → R15
- TM-05 Xe tank temperature (Xe density near the critical region is temperature-sensitive) → R15
- TM-06 regulated Xe pressure (regulator outlet) → R15
- TM-07 plenum / feed pressure P_feed (flight low-pressure sensing is a specification gap) → R15
- TM-08 feed temperature T_feed → R15
